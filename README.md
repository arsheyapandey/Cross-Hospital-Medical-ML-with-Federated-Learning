# Cross-Hospital-Medical-ML-with-Federated-Learning
This project presents a Privacy-Aware Federated Learning framework for heart disease prediction using the UCI Heart Disease Dataset. The system addresses challenges arising from cross-hospital data distribution differences while preserving patient privacy. Instead of centralizing sensitive medical records, multiple institutions collaboratively train a shared machine learning model through Federated Learning, ensuring that raw patient data never leaves local environments. To further enhance security and confidentiality, privacy-preserving mechanisms are integrated into the training process. The project includes data preprocessing, feature engineering, distributed model training, and comprehensive performance evaluation. Experimental results are assessed using key classification metrics such as Accuracy, ROC-AUC Score, Precision, Recall, and F1-Score. This work demonstrates how privacy-preserving AI techniques can enable secure and effective healthcare analytics while maintaining regulatory compliance and protecting sensitive patient information.
